## 1. 通知开关与测试提醒

- [ ] 打开 `ALR` → 初始应为 OFF
- [ ] 开启 → 系统通知权限弹窗出现
- [ ] 允许 → 状态 ON，显示已排条数
- [ ] 拒绝 → 显示「已拒绝」，可继续建/改/查待办，不反复弹系统框
- [ ] 系统设置里重新允许 → 回应用再次开启 → 能正常排程
- [ ] 点「发送测试提醒（5 秒后）」→ 前台收到通知
- [ ] 通知小图标是白色 H，强调色为信号红（不是默认白块/灰块）
- [ ] 点击测试通知 → 只打开应用，不错误打开某条待办
- [ ] 关闭开关 → 状态 OFF、已排条数归零、通知栏无残留
- [ ] 再次开启 → 已排条数恢复

## 2. 单次待办提醒

- [ ] 新建待办，选「5 分钟后」→ 创建成功
- [ ] 回到 `ALR` → 已排条数 +1
- [ ] 前台等待 → 到点收到通知，标题「待办提醒」，正文为待办标题
- [ ] 点击通知 → 打开对应待办详情
- [ ] 退到后台等待 → 到点收到通知，点击能打开详情
- [ ] 从最近任务划掉应用（杀进程）→ 到点仍收到，点击冷启动进详情
- [ ] 重启手机（可选）→ 到点是否收到；记录「收到 / 未收到 / 打开应用后才恢复」
- [ ] 编辑提醒时间到更晚 → 旧时间不响，新时间响
- [ ] 完成待办 → 不再响
- [ ] 删除待办 → 不再响
- [ ] 编辑里选「清除」→ 不再响
- [ ] 同一待办连续改 2–3 次时间 → 只有最后一次响，无重复

## 3. 循环任务提醒
