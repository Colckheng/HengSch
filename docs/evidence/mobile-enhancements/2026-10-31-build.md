## 2026-11-01 修复（真机验收前）

| 问题 | 修复 |
|---|---|
| 提醒设置开关只改弹窗本地状态，Provider 不知道已开启 → 不会随待办变化重排 | 开关、权限、已排数收敛到 `ReminderContext`；弹窗通过 `useReminder()` 读取与操作，开启/关闭后 Provider 立即生效 |
| 通知点击的 last response 未清除，冷启动可能重复打开同一条 | 处理完冷启动/实时响应后调用 `clearLastNotificationResponseAsync()` |
| 滑动手势 `PanResponder` 闭包持有旧的 `onOpenChange`，关闭可能清不掉 openId | 用 ref 持有最新回调 |
| 已完成待办左滑仍显示「完成」且可「稍后」 | 已完成显示「恢复」；稍后 1h 禁用；点已滑开的卡片先收起而不是打开详情 |
| 小组件刷新从 JS 原生模块线程直接调 `AppWidgetManager` | `refreshAll` 切主线程 `Handler(Looper.getMainLooper())` |
