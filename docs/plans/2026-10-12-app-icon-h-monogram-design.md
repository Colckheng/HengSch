# 应用图标重设计：H. 字标（2026-10-12）

## 背景

旧图标（`public/assets/icon.ico`，单帧 32px 彩色噪点）与桌面端 Swiss Precision 纸感 UI 完全脱节。本次按设计语言（纸面/墨黑/信号红/发丝线/直角）重设计，并按 HARD GATE 先行提交本文档。

## 候选与决策

共设计四个方向，均按 1024 设计网格、平涂、无渐变、无圆角绘制，渲染成多尺寸 .ico 后经实景对比选定：

| 方向 | 构成 | 结论 |
| --- | --- | --- |
| A 信号勾 | 纸面 + 瑞士红直角勾 | 语义最直白，但与常见待办类图标同质 |
| B 墨块纸勾 | 墨黑满铺 + 纸白勾 + 红方点 | 对比最强，仍属「勾」类套路 |
| C 红格 | 4×4 发丝线网格一格填红 | 大图最有海报感，16px 退化为小红点，可读性不足 |
| **D H. 字标** | **几何 H + 红色句点方块** | **定稿**：品牌字标、期刊气质，16px 下依然刚健 |

选择理由：托盘/任务栏识别的本质是「认出这是哪个应用」（identity），而非表达功能；D 在最小尺寸下笔画最粗、辨识度最高，且句点方块与 UI 里开关激活态、信号红的用法同源。

## 定稿规格

- 画布：1024×1024，满铺直角方块（无圆角、无阴影）
- 色板：纸面 `#FAFAF8`、墨黑 `#0A0A0A`、信号红 `#E63329`、发丝线 `#E5E5E3`
- H（墨黑，直角矩形拼合）：
  - 左竖条 `x 248–368, y 176–848`（宽 120）
  - 右竖条 `x 656–776, y 176–848`（宽 120）
  - 横梁 `x 368–656, y 452–572`（高 120）
- 句点（信号红）：`x 824–936, y 732–844`（112×112），底缘略高于 H 基线做视觉对齐
- 发丝线内框：内缩 2px、线宽 4、色 `#E5E5E3`，仅 ≥24px 尺寸渲染（≤32px 档简化版不画内框）

## 尺寸与产出

- 尺寸档：16 / 24 / 32 / 48 / 64 / 128 / 256，全部 PNG-in-ICO 容器
- 引用点全覆盖：
  - `electron-builder.json` → `win.icon`：exe 图标 + NSIS 安装器图标
  - vite `public/` → `dist/assets/`：主窗口图标（dev 与打包均取该文件）
  - `src/main/tray.ts`：托盘图标（dev 用 `public/assets/icon.ico`，打包用 `dist/assets/icon.ico`）

## 构建管线（可复现）

1. 每尺寸单独生成 SVG（`width/height` = 目标像素，`viewBox="0 0 1024 1024"`；headless Edge 对独立 SVG 按原生尺寸渲染，窗口即像素）
2. headless Edge `--screenshot` 渲染 PNG（独立 `--user-data-dir`，避免与常驻浏览器实例冲突）
3. Node 脚本拼 ICO 容器（6 字节头 + 16 字节/条目 + PNG 数据块）
4. 校验：PNG 签名逐条目字节校验（注意 System.Drawing.Icon 的尺寸搜索把 256 档宽高字节 0 误读为 0，报最大帧 128 属已知误报，不代表容器有问题）

## 门禁

`tsc + vite build`、`eslint --max-warnings 0`、根 `npm test` 全绿后替换 `public/assets/icon.ico` 并重新打包。
